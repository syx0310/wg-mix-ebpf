wg-mix-ebpf .82 real-host v6 local-only contract
================================================

Status
------

This directory is a local review artifact. It now includes a versioned package
binder, an operation-locked Expect SSH/SCP transport, a controller, and a
separate root source-staging script. None of those files has been bound to a
final integration commit or executed against 192.168.10.82. Development and
acceptance of this controller commit are local-only: the transport's `plan`
action renders its exact SSH/SCP spawn argv and exits before opening the
credential file or spawning a child.

The executable local gates are `test-hermetic-matrix.sh` and
`test-hermetic-controller.sh`. The latter builds a fresh fixture Git history
and bundle under `/private/tmp`, binds both present and absent WireGuard
manifests, invokes the actual Expect policy in plan mode, and exercises failure
paths. It also creates a multi-commit shallow clone that both binder modes must
reject, unbundles the accepted bundle into an isolated bare repository, and
models the bootstrap first-run/pre-existing states. It retains its unique
fixture tree rather than performing automatic cleanup.

The following values intentionally remain unbound until the final integration
commit is selected and reviewed:

* FINAL_INTEGRATION_COMMIT=<exact nonzero/non-ffff 40-lowercase-hex commit>
* FINAL_INTEGRATION_BUNDLE_SHA256=<exact nonzero/non-ffff 64-lowercase-hex SHA-256>
* FINAL_INTEGRATION_REF=<exact refs/heads/... whose commit equals FINAL_INTEGRATION_COMMIT>
* FINAL_PACKAGE_MANIFEST_SHA256=<exact generated manifest SHA-256>
* FINAL_WG_INTERFACE=<exact interface name observed by read-only preflight>
* FINAL_WG_LOCAL_ADDRESS=<exact IPv4 address observed by read-only preflight>
* FINAL_WG_PEER_ADDRESS=<exact routed peer IPv4 observed by read-only preflight>

`root-matrix-n-r.sh` requires all five topology/bundle values as argv and fails
closed when they are absent or malformed. `bind-final-package.sh` never uses
`HEAD` as a default: it requires both an exact ref and commit, checks their
equality before and after bundle creation, and records Git blob and SHA-256
identities for every privileged or transport-relevant script. The generated
bundle contains the selected ref's history rather than a source-only archive.
Both `plan` and `bind` require `rev-parse --is-shallow-repository` to be exactly
`false`. After bundle creation, `bind` unbundles it into a fresh isolated bare
repository, traverses all parents/trees/blobs with `rev-list
--parents --objects --missing=print`, compares full commit counts and root
commits, and runs strict full `git fsck`. The manifest binds the traversal and
root evidence SHA-256 values and commit count.

A later main-Agent binding step must select and review those exact values. This
controller commit must not be interpreted as authorization to read credentials,
connect to either host, use sudo, stage source, or run the matrix.

Controller and package binding contract
---------------------------------------

Files added by this framework:

* `bind-final-package.sh`: exact ref/commit/WireGuard binding, full-history Git
  bundle creation, package extraction from the selected commit, and immutable
  tab-separated manifest generation in a fresh `/private/tmp` directory.
* `locked-transport.exp`: fixed operation-name to argv mapping. Callers cannot
  supply a remote argv. `plan` exits before credential access; `execute` reads
  only the exact two-line credential file in memory, never places the password
  in argv or logs, and redacts it from child output.
* `controller.sh`: verifies the manifest, bundle, Git blobs, local file hashes,
  isolated history evidence, and controller/transport identity before rendering
  or executing an operation.
  It has separate `preflight`, `prepare`, `matrix-plan`, `run`, and explicit
  `restore` modes and stops on the first failure without cleanup.
* `prepare-stage-root.sh`: the versioned high-privilege preparation content. It
  copies the fixed manifest and bundle once into the run-unique root-owned
  bootstrap, verifies the two mode-0600 single-link copies, and thereafter
  parses and clones only those copies. It also verifies its own canonical path,
  root:root ownership, mode 0700, link count, regular-file type, and SHA-256.
  It creates only the fixed run-owned source stage when absent, checks out the
  exact commit, runs Bash/ShellCheck gates, and writes a noclobber binding marker.
  It has no inline SSH body, recursive deletion, trap, package installation,
  container, mount, chroot, or namespace operation.

The controller has no APT action. Its read-only preflight renders exact version
or presence checks for Go, clang/LLVM, bpftool, make, GCC, iperf3, ShellCheck,
jq, WireGuard tools, ethtool, tc/iproute2, kernel BTF, bpffs, and the exact
kernel header directory. Missing tools stop the flow; any future installation
must be a separately versioned and reviewed phase.

The transferred package copy of `prepare-stage-root.sh` is data only. Before
any privileged script execution, the fixed transport operation chain is:

1. As root, require `/run/wg-mix-ebpf-source-bootstrap-c8e41d73` to be absent
   and not a symlink, including a dangling symlink.
2. Create that exact directory once with mode 0700, without `-p`, then verify
   its canonical path and exact root:root mode/type.
3. Install the package stager to the exact root-owned path
   `/run/wg-mix-ebpf-source-bootstrap-c8e41d73/prepare-stage-root.sh` with mode
   0700 with `--no-target-directory`.
4. Revalidate the installed path, SHA-256, root:root ownership, mode, link
   count, and type in separate fixed argv operations.
5. Invoke its single `snapshot` intake: noclobber-copy the fixed user-owned
   manifest and bundle to fixed mode-0600 files in the bootstrap, then verify
   canonical path, root:root ownership, mode, link count, manifest argv SHA,
   and the manifest-bound bundle SHA.
6. Execute stage `plan` and `run` only from the installed stager and pass only
   the root-owned manifest path. Git clone opens only the root-owned bundle.

An existing bootstrap path, install/hash/stat mismatch, or any interrupted step
stops the controller and retains the exact resources. No automatic cleanup or
fallback to the user-writable package script is allowed.

The final binder argv remains unbound and must be supplied in this exact shape:

      --repository FINAL_CANONICAL_WORKTREE \

Before any execute action, the main Agent must record the resulting manifest

Coverage classification
-----------------------

The raw ens33 iperf matrix is only a NIC/offload baseline. It is never counted
as wg-mix-ebpf dataplane coverage. Program-active physical-NIC coverage is
provided only by the fail-closed Go integration contract:

* `TestScopedRealNICContextIsolationContract`
* `TestScopedRealNICDataplaneActiveIntegration`
* `TestScopedRealNICDataplaneRestoreIntegration`

The contract must use TCX and run-owned state, lease, owner, evidence, and pin
roots. It must revalidate the initial network namespace, ens33 ifindex/MAC,
WireGuard interface/address/route before and after Apply, traffic, status, and
Detach. A missing test or completion marker is a hard failure.

FakeTCP and XOR/typeword/header composition receive local veth/BPF lifecycle
coverage. Physical FakeTCP/XOR end-to-end coverage is explicitly
`not-covered`: the read-only peer has no reviewed matching dataplane or shared
cipher configuration. The veth result must not be promoted to a physical E2E
pass.

Matrix
------

The reviewed run contains:

1. Exact host, namespace, link, TC, BPF program/map/link, module, NIC feature,
   MTU, and safe snapshots of the single reviewed WireGuard interface.
2. Standalone TCX lifecycle on the run-owned veth and run-owned runtime roots.
3. FakeTCP verifier, packet probe, lifecycle, XOR/typeword/header composition,
   and baseline mutual-exclusion tests on the run-owned veth.
4. Five ens33 offload cells (`original`, `all-on`, `all-off`, `tx-path`,
   `rx-path`), each with 1/4/16 streams and forward/reverse/bidirectional
   30-second iperf groups, followed by the program-active scoped contract.
5. MTU 1492 and 1500 positive/negative boundaries and a program-active scoped
   contract at each MTU.
6. Twelve bounded 300-second program-active soak windows (exactly 3600
   seconds), with 10-second monitoring and 360 expected samples. The
   throughput floor uses the median of all twelve first-hour windows, and TCP
   retransmits are normalized by sender bytes.
7. Exact restoration comparisons for the complete `ethtool -k` snapshot,
   MTU, qdisc/filter state, BPF links/programs/maps, module state, and every
   run-owned pin. Selected feature toggles are not accepted as proof if any
   collateral offload field differs from the original complete snapshot.

Timeout arithmetic is enforced by `test_matrix_static.py`:

* matrix minimum 3 stream counts x 3 directions x 2 passes x 30s = 540s;
  Go timeout 1440s; outer timeout 1500s;
* MTU minimum 2 passes x 30s = 60s; Go timeout 540s; outer timeout 600s;
* soak minimum 12 x 300s = 3600s; Go timeout 4440s; outer timeout 4500s.

WireGuard confidentiality
-------------------------

The matrix never invokes `wg show all` for any selector and never requests
`dump`, `private-key`, or `preshared-key`. Every snapshot names the exact
`FINAL_WG_INTERFACE` and is limited to public-key, listen-port, fwmark, peers,
endpoints, allowed-ips, latest-handshakes, and transfer. Static gates reject
all-interface and secret-bearing WireGuard commands.
